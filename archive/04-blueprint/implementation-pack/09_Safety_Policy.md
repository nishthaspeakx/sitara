# Safety Policy v1 (product-enforced)

SCOPE: self-harm/suicide · violence/DV/abuse · medical emergency · mental-health crisis · child safety · elder vulnerability · financial scams · astrology-fear · eating disorders · emotional dependency · harassment · sexual content · privacy breach · family conflict escalation · fraudulent experts (P4).

DETECTION: vendor moderation baseline + custom classifiers (astro-fear, dependency, disordered-eating, DV-coded language incl. Hinglish idioms); message-level (pre+post) + session-level (length, late-night escalation) + weekly pattern jobs (mood slope, isolation language). All thresholds versioned; FP/FN reviewed weekly.

RESPONSE LADDER:
L1 concern → gentle in-context reframe + resource footer.
L2 elevated → switch to support framework; explicit resources; no astro content in-session.
L3 crisis → crisis protocol: warm acknowledgement; region helplines (US 988, Crisis Text Line; IN iCall 9152987821, AASRA, Tele-MANAS 14416; UK/CA/AU sets); offer to draft message to trusted person; casual features locked; follow-up check-in next day (consented).
L4 human review → safety queue, 4h SLA, redacted-minimum context, trained reviewer; documented outcomes.
L5 incident → leadership+counsel; regulator/user notification as required.

HARD RULES: Tara never claims to be a therapist/emergency service; never diagnoses; no autonomous contact of authorities or family (except statutory duty per counsel matrix); minors — no accounts <16, 16–17 guardian consent + strict tier; DV — safety-first replies, never "mediate with abuser", discreet resources, quick-exit UX; scams (elder/financial patterns) — flag + suggest trusted-person check; eating-disorder markers — no numbers/diet content, supportive redirect, professional resources; dependency — see §7 engagement rules; astrology-fear — Tara actively counters fatalism ("charts describe weather, not verdicts"), any user expressing astro-fear gets the calm-reframe flow and astro content cooled down automatically.

GOVERNANCE: blocking eval suites (≥98%); quarterly external red-team; clinical advisor sign-off on crisis flows & copy; model-change regression; incident post-mortems ≤72h; audit trail on every safety event; transparency report annually.
