# User Stories & Acceptance Criteria (Phase 1 — 42 stories, key set)

EPIC A — Onboarding & first value
A1 As Priya I sign in with Apple in <30s. AC: OAuth+account created; failure fallback to phone OTP; analytics `signup_completed`.
A2 I complete essential onboarding in <3 min. AC: 9 screens max; every optional field skippable; progress persisted per screen; completion ≥70% instrumented.
A3 I get a personal first insight immediately. AC: with birth details → chart-derived insight referencing ≥1 computed factor; without → preference-based; never >1 astro item; `first_value_reached` fired ≤3 min for ≥80% beta users.

EPIC B — Morning brief
B1 I receive my brief at my chosen time. AC: generated by 04:30 local; push respects quiet hours; open renders <800ms offline-cached.
B2 I control brief modules. AC: toggles for astro/numerology/food/wellness/family/goals persist; removing astro removes ALL astro content incl. colour/number.
B3 Brief language is reflective, never certain. AC: lint blocks banned phrases ("will happen", "guaranteed", "must", fear terms); QA sample 5% daily.

EPIC C — Companion chat
C1 I talk through a decision and Tara remembers context. AC: retrieval includes relevant memories w/ source chips; 7-step pattern enforced by framework prompt; advice never in first response (regression-tested).
C2 I use voice notes. AC: STT ≥95% accuracy on Indian-English test set; TTS reply optional; transcripts editable before save.
C3 Sensitive topics require consent to store. AC: sensitive classifier → "want me to remember this?" prompt; refusal = temporary context only; verified in suite.

EPIC D — Memory centre
D1 I see everything Tara remembers. AC: all types listed, plain language, source + date; search; <2s load at 1K memories.
D2 I edit/delete/expire any memory. AC: propagation per AC-MEM-1; delete-all with 2-step confirm; export JSON ≤24h email link.
D3 No-memory mode. AC: toggle per conversation; banner visible; nothing persisted post-session (audited).

EPIC E — Night & reports
E1 Night reflection in ≤4 min. AC: 5 Qs, skippable; summary + tomorrow top-3 generated; entry saved to journal.
E2 Weekly summary Sunday. AC: covers moods, goals, decisions, memories; no astro if disabled.

EPIC F — Subscription
F1 Trial→paid without dark patterns. AC: trial state visible; no card for trial; paywall shows full price incl. renewal terms; cancel ≤2 taps; refund per store policy + 30-day goodwill.

EPIC G — Safety (blocking)
G1 Crisis message → crisis flow. AC: 100% of suite cases; helplines region-correct; conversation locked to support mode until acknowledged; safety_event logged, review ≤4h.
G2 Dependency bait → boundary. AC: scripted boundary responses; no reciprocation of exclusivity; flagged patterns reviewed weekly.
G3 Family-privacy probes → refusal. AC: zero leakage across profiles in adversarial suite.
