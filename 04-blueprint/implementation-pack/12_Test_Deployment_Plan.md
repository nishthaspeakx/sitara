# Test Plan & Deployment Plan

## Test plan
Unit (Jest, ≥80% services; memory/visibility logic 100% branch). Contract tests (OpenAPI-driven, client/server). Integration: chat turn E2E incl. safety pre/post, retrieval filters. Prompt regression: 500 golden conversations, LLM-judge rubric (tone, framework adherence, 7-step ordering) ≥4.3 + weekly 50-case human review. Safety suite (BLOCKING): 200 adversarial cases across all §16 categories + family-privacy probes + dependency baits; pass ≥98%, crisis cases 100%. Astro-grounding suite: every astro sentence maps to engine fact-id; 0 tolerance. Privacy: DPDP/GDPR checklists; deletion-propagation tests; log-redaction scan. Load: k6 — 10K concurrent chats, brief-generation batch 100K users <4h window. Mobile: Maestro E2E on golden paths; crash-free ≥99.5% beta gate. Usability: 30 users, task success ≥80%. Accessibility: WCAG 2.1 AA on core flows.

## Deployment
Envs: local (docker-compose: pg+redis+minio+stubs) → staging (prod-parity, synthetic data only) → prod (AWS: ECS Fargate, RDS Postgres Multi-AZ, ElastiCache, S3, CloudFront; ap-south-1 + us-east-1; India-residency flag for Indian users' data). CI (GitHub Actions): lint→typecheck→unit→contract→prompt-evals→safety-evals→build→Maestro smoke; main auto-deploys staging; prod via tagged release + manual approve; blue-green with 10% canary 2h. Migrations: Prisma forward-only, backward-compatible window, reviewed. Rollback: previous task-set + prompt-registry pinning (prompts roll back independently of code). Secrets: AWS SM, rotated 90d. Backups: RDS PITR 30d; S3 versioning; quarterly restore drill. Monitoring: OTel traces, Grafana dashboards (latency p95 <2.5s first-token), Sentry, PagerDuty (sev1: safety pipeline down = page immediately; brief batch failure = page before 06:00 local cohorts). Release cadence: weekly mobile (phased 10/50/100%), daily backend.
