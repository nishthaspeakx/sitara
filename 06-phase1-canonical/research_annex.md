## A. Vedic astrology APIs & engines
**Swiss Ephemeris (Astrodienst).** Dual licence: free only for open-source/personal use; closed-source commercial products require the professional licence — pages show CHF 700 ("unlimited") vs CHF 750 first licence (discrepancy UNVERIFIED; budget CHF 750). Includes source, libraries, ephemeris files. Precision ~0.001 arc-sec vs JPL. Provides astronomy + ayanamsas + houses only — NOT panchang/muhurat/festival logic (explicit in Astrodienst docs). Python binding: pyswisseph (actively maintained). Sources: astro.com/swisseph pages, github.com/astrorigin/pyswisseph.
**DivineAPI.** Most complete Vedic coverage found: full panchang incl. Yamaganda/Gulikai, dedicated Muhurat Finder (marriage/griha pravesh/vehicle/business), festival calendars incl. Tamil/Malayalam + Gowri Panchangam/Nalla Neram, D1–D60, Vimshottari/Yogini/Jaimini dashas, Grah Gochar. Tiers: Sampoorna $19/mo (100K req) · Ananta $79/mo (600K) · Prakash $149/mo (2M). 99.9% uptime self-reported (UNVERIFIED — no public status page). Ayanamsa options undisclosed (verify in trial). 14-day trial (card required). Source: divineapi.com/pricing.
**Prokerala.** Panchang/choghadiya, Lahiri/Raman/KP ayanamsas, Vimshottari, Kundli matching, numerology (Chaldean+Pythagorean). $19–99/mo tiers (5K free credits). ToS: cache must refresh ≤24h and be purged on termination — cannot be a system of record; no SLA; data processed in India; no GDPR language found. Sources: api.prokerala.com pricing/tos/privacy.
**AstrologyAPI.com (Vedic Rishi).** Good chart/dasha/Gochara coverage; 99.99% uptime self-claimed; privacy policy cites the superseded UK DPA 1998 — compliance red flag for UK/EU users. From ₹1,500/mo.
**VedicAstroAPI.** 21 output languages (differentiator, but our facts must be engine-native); coverage detail and ayanamsa options unverified; ₹1,499–2,499/mo entry.
**Drik Panchang / AstroSage.** No commercial API or licensing programme found — reference/validation sources only.
**Architectural conclusion adopted (§5):** internal SwissEph engine for charts/nakshatra/dasha/transits (deterministic, zero marginal cost, private); DivineAPI for panchang/muhurat/festivals at launch + validation oracle; Prokerala cross-check; in-house panchang logic is the post-launch cost-reduction path; timezone/geocoding handled by our own resolver (no astrology vendor publishes credible historical-DST accuracy).

## B. Voice — TTS/STT (8 languages)
**ElevenLabs.** v3: broadest language reach (incl. all 6 Indic) but NOT low-latency; Flash v2.5 (~75ms model latency) and Multilingual v2 confirm only EN/HI/TA of our set (whether Flash has added GU/PA/MR/TE: UNVERIFIED → bake-off test). Professional Voice Clone must be created by the artist's own verified account then shared — workable with contract. Default terms grant ElevenLabs training rights on voice data — must be struck in enterprise contract. $0.05–0.10/1K chars; Scribe STT ~150ms streaming.
**Azure AI Speech.** Only provider with confirmed native neural voices across en-IN, hi-IN, gu-IN, pa-IN, mr-IN, ta-IN, te-IN. Custom Neural Voice (studio artist, gated approval) + Personal Voice (consent-clip cloning). $16–24/1M chars, committed tiers → ~$7.50/1M. Viseme events confirmed en-US only → regional lip-sync uses timestamps/amplitude. Streaming TTFB unpublished (UNVERIFIED → bake-off).
**Sarvam AI.** Bulbul v3 TTS (11 languages; native-script input required — critical for Hinglish handling); Saaras v3 STT with explicit code-mix preservation — strongest Indic STT signal in third-party benchmark (8.3/10, behind Soniox/ElevenLabs composite). ₹30/hr STT. No voice cloning. India-sovereign positioning; formal residency/compliance doc UNVERIFIED → contract.
**Cartesia Sonic.** Native-Hinglish product, ~40ms TTFB claim, India data centres; cloning/commercial terms undisclosed (UNVERIFIED) → bake-off candidate.
**Deepgram Nova-3.** Strong EN; added GU, improved MR/TA/TE; Hinglish code-switch capability not documented. ~$0.005–0.008/min.
**Google Chirp.** 5 of 6 regional STT locales still Preview → fallback only. **AWS Polly** hi-IN/en-IN only → ruled out. **OpenAI TTS** Indic quality unverified → ruled out for regional. **PlayHT** possible shutdown/instability reports → excluded. **AI4Bharat/Bhasini** MOS ~3.6–3.9 → below premium bar.
**Cost planning figure:** blended $0.017–0.020/voice-minute (Azure/Sarvam-forward) to $0.035–0.05 (ElevenLabs-heavy); get direct volume quotes (Azure committed tiers materially cheaper).
**Verdict adopted (§3):** native voice models per language unified by one Voice Bible; anchor clone on ElevenLabs (EN/Hinglish/HI) + Azure CNV cast artists (GU/PA/MR/TA/TE); Sarvam Saaras primary Indic/Hinglish STT, Deepgram EN; Azure stock voices universal failover.

## C. Avatar technology (Next.js web, millions of users)
**Rive.** Free runtime, no per-user royalty (editor seats only, ~$32–49/seat/mo); first-party @rive-app/react-canvas; state machines map directly to our 15 states; files tens–hundreds of KB; community-proven viseme lip-sync pattern (state-machine number inputs driven by audio playback position). Winner: 22/25 on our scorecard.
**Live2D Cubism Web.** Premium look; but licensing becomes per-region/per-platform recurring fees past ¥10M revenue; unofficial React bindings; 2–15MB runtime models. 18/25.
**three-vrm (3D).** Heaviest build + mid-range-Android browser perf risk. 17/25.
**Streamed video avatars (D-ID/HeyGen/Azure Avatar/Soul Machines).** Per-minute billing (+idle endpoint fees) → $500K–$4M+/month at millions of users — categorically ruled out as primary. 16/25.
**Lottie/dotLottie.** No credible continuous lip-sync — used only as inspiration for the static-fallback crossfades.
**Lip-sync:** ElevenLabs streaming-with-timestamps (character-level) confirmed; Azure viseme events en-US-only confirmed; Rhubarb = offline only (pre-rendered briefs); amplitude fallback always available. Tiered approach adopted (§4.6).
